🚀 Featured Project — Proton Web Server

High-Performance Event-Driven Web Server, Reverse Proxy & API Gateway (C)

A production-grade HTTP server written from scratch in pure C, inspired by NGINX but redesigned for modern infrastructure, observability, and API-gateway use cases.

🔗 Repository: https://github.com/MaximKoblyuk/proton-web

📜 License: MIT
⚡ Focus: Performance • Reliability • Explicit memory control

🧠 Why Proton?

⚙️ Event-driven architecture (epoll, non-blocking I/O)

🧵 Master / Worker process model with zero-downtime reloads

🧠 Custom memory pools & zero-copy proxying

🧩 Modular C API (static & future dynamic modules)

🌐 Reverse proxy & load balancing

🔐 API Gateway features (JWT, rate-limiting — planned)

📊 Built-in observability (Prometheus metrics)
